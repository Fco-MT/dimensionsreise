# 次元之旅（Dimensionsreise）

🌐 [English](README.md) · [Deutsch](README.de.md) · **中文**

**同一事件 – 不同世界 – 全新視角**

一個互動式動畫網頁，講解從一維（1D）到五維（5D）的空間維度。
一隻貓、一顆球、五個世界：同一件事在每個維度中上演——
一次從貓自己的視角來看，一次從更高一維的生命的視角來看。

**➡️ 線上頁面：https://fco-mt.github.io/dimensionsreise/**

## 頁面內容

- **五個世界並列呈現：** 線（1D）、面（2D）、空間（3D）、四維空間與五維空間——同一個故事在每一欄中同步進行。
- **三種可選的事件**（在「設定」中選擇）：
  - 把球舉過障礙物
  - 手指穿過貓的世界
  - 僅日常生活（不介入）
- **視角轉換：** 貓實際上看到什麼？永遠只是一幅比她的世界少一個維度的圖像。而更高維度的生命又會看到什麼？
- **操作方式：** 播放、暫停、重設動畫，用滑桿調整速度與進度；可將單一維度放大顯示——很適合課堂上用投影機展示。
- **三種語言：** Deutsch · English · 中文（一鍵切換）

## 背後的原理

> 更高維度的生命可以將物體移向一個在較低維度中不存在的方向。

在一個世界裡不可能的事（球從密封的玻璃櫃中消失），
在高一個維度中卻輕而易舉。

## 技術說明

- 只有一個檔案：[`index.html`](index.html)——無需建置步驟、無外部依賴（僅使用 Google Fonts 字型）
- 動畫以純 JavaScript 在 HTML canvas 上繪製
- 響應式設計（從桌面到智慧型手機），支援 `prefers-reduced-motion`
- 透過 GitHub Pages 託管（分支 `main`，資料夾 `/`）

## 自行架設與修改

只需要 `index.html` 這一個檔案——下載後直接在瀏覽器中開啟，
或放到任何網頁伺服器上即可。三種語言的所有文字都集中在
檔案指令碼區段中的 `T` 物件裡。
